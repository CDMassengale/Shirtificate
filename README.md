# CS50 Shirtificate Generator

## Description
The CS50 Shirtificate Generator is a Python program that creates a personalized PDF certificate for users who have completed CS50.
The program collects the user's name and generates a shirt-themed certificate featuring their name and the text "took CS50."

## Tools and Languages
- **Python:** Programming language used to develop the application.
- **Visual Studio Code:** Code editor used to write and run the program.
- **FPDF:** Python library used to generate and format PDF documents.
- **PNG:** Image format used for the shirt design.

## Features
- **User Input:** Prompts users to enter their name.
- **PDF Generation:** Creates a downloadable PDF certificate.
- **Custom Design:** Includes a shirt image and a personalized heading.
- **Text Formatting:** Uses custom font sizes, alignment, and white text.
- **Automatic Export:** Saves the completed certificate as `shirtificate.pdf`.

## What I Built
I developed a Python application that automatically generates personalized CS50 Shirtificates. I used the FPDF library to create a PDF document, 
insert a custom shirt image, and format text using different font sizes, colors, and alignment. The program takes the user's name as input and incorporates 
it into the finished certificate before exporting the PDF file.
